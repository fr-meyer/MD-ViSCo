# Datasets Directory

Place the required datasets in the following structure under the project root:

```
datasets/
├── UCI/           # For the UCI dataset (preprocessed format from NABNet)
└── PulseDB/       # For the PulseDB v1 dataset
```
[See UCI dataset instructions](UCI/UCI_README.md)

[See PulseDB dataset instructions](PulseDB/PulseDB_README.md)
